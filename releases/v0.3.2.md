## PiP Studio 0.3.2

### 下载 / Download

- [国内版（默认中文，国内账号与服务）](https://github.com/RonnyLin/pip-studio-releases/releases/download/v0.3.2/Pip-Studio-CN-Setup.exe)

Both editions support Chinese / English switching. Windows 10/11 x64.

### 更新内容

- 摄像头默认使用“无效果”方案，直接显示原始画面，不自动开启粒子或光影。
- 旧设置首次升级也会回到原始画面，保留所有已保存方案；之后手动选择的方案仍会记住。
- 官网登录显示具体错误，例如“验证码错误”，并用清晰的错误样式提示。
- 保留边录制边生成 MP4、停止后回放确认和原始录像故障恢复。

### What's new

- The camera starts with No effects, showing the original picture without automatic particles or lighting.
- Existing settings switch to the original camera once on upgrade. Saved scenes are preserved, and later manual selections are remembered.
- Website sign-in shows specific verification errors with clear error styling.
- Includes MP4 processing while recording, playback review, and original-capture recovery.

### Integrity / 校验

`SHA256SUMS.txt` covers both editions. Update metadata also validates installers with SHA-512.

This release is unsigned and may show a Microsoft Defender SmartScreen warning. Integrity checks do not replace Windows code-signing.
