# PiP Studio 0.3.0

This release brings the current Windows desktop experience to PiP Studio's
global download channel.

## Highlights

- Record an entire display or select a custom region, with a visible countdown
  and a fixed recording boundary.
- Preview a finished recording before keeping it, or discard it without adding
  it to recent files.
- Improved digital-avatar head direction, fingertip tracking, window dragging,
  and close controls.
- Added three gesture-driven Daylight Spirit scenes: crane, koi, and deer.
- Removed the retired depth model and legacy inference pipeline from the
  installer while keeping local hand tracking and MP4 export.

## Important workflow note

Camera and digital-avatar overlays are independent always-on-top windows. Test a
short recording before a long session when those overlays must appear in the
final video.

## Windows notice

The 0.3.0 installer is not yet code-signed. Windows may display an unknown
publisher or SmartScreen warning even when the downloaded SHA-256 checksum
matches `SHA256SUMS.txt`.
