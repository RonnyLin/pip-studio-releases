## PiP Studio 0.3.1

### 下载 / Download

- [国内版（中文默认，国内账号与服务）](https://github.com/RonnyLin/pip-studio-releases/releases/download/v0.3.1/Pip-Studio-CN-Setup.exe)

Both editions support Chinese / English switching. Windows 10/11 x64.

### 更新内容

- MP4 在录制期间生成，停止后无需默认重新编码整段视频，更快进入回放确认。
- 不支持直接录制 MP4 的电脑，改为录制期间后台转换，并检测可用的硬件编码器。
- 转换异常时保留原始录像并尝试恢复，避免丢失已录制的内容。
- 回放不再等待封面生成；确认保存后立即打开所在目录。
- 更新媒体组件，改善 MP4 格式兼容性。
- 海外版的后续更新继续使用海外账号和服务，不会切回国内版。

### What's new

- MP4 files are prepared while recording, so stopping no longer normally starts a full-video re-encode.
- Compatible fallback recording converts in the background, using a verified hardware encoder when available.
- Recovery keeps the original capture if MP4 processing fails.
- Playback review no longer waits for a cover image; saving opens the file's folder immediately.
- Updated media components improve MP4 compatibility.
- Global-edition updates stay on the global edition and overseas services.

### Integrity / 校验

`SHA256SUMS.txt` covers both editions. Update metadata also validates the installer with SHA-512.

Windows code-signing is separate from these integrity checks. This release is unsigned and may show a Microsoft Defender SmartScreen warning.
