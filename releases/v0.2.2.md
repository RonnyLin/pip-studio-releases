# PiP Studio 0.2.2

This release adds the current Windows installer to PiP Studio's global download
channel.

## Highlights

- Camera and digital-avatar overlays can run together.
- Includes the Electron updater metadata and blockmap for integrity checks.
- Includes `SHA256SUMS.txt` for independent download verification.

## Windows notice

The 0.2.2 installer is not yet code-signed. Windows may display an unknown
publisher or SmartScreen warning even when the downloaded SHA-256 checksum
matches the release checksum.
